# 41音カリンバ・練習ステーション（Seeds 3段式対応）

**Seeds 41キー 3段式クロマチックカリンバ**（上段17・中段17・下段7／中段中央=`1 / C4`／音域 F3〜F6）専用の練習・実演デモ・41本チューニングWebアプリです。

## 公開URL（GitHub Pages）

- https://onoderaakira01027-coder.github.io/kalimba-41-practice/

HTTPSで公開されているため、スマートフォン・PCどちらからでも1タップ起動でき、マイクを使った41本チューニング機能もそのまま利用できます。

## 主な機能

- **練習モード**：17レーン降下ノート／数字・ドレミ・音名切替／スロー再生／区間ループ／片手親指フィルタ／任意MIDI読み込み
- **カリンバ実演デモモード**：3音色切替・41音テスト・手作業編曲版『Carry On My Wayward Son』（284音・F3〜F6 100%適合）を標準内蔵
- **41本チューニング専用モード**：目標音 vs 実測音・ズレ量比較カード、ハンマーで上端／先端どちらを叩くかのアニメーション図示、お試しプレビュー、41本チェック機能

## 同梱ファイル

- `index.html`：アプリ本体（単一HTML・外部CDN不使用）
- `music/Kansas - Carry On My Wayward Son (41-Key Kalimba Edition).mid`：Seeds 41キー専用編曲MIDI
